# EnderLilies Custom Rollback

This project can generate patch packages to roll back certain character skills in ENDER LILIES to specific historical versions.

Currently, this project includes a batch script [pak.bat](pak.bat) and the Release executable of [UnrealReZen](https://github.com/rm-NoobInCoding/UnrealReZen), demonstrating how to generate `Skill Rollback MOD/Patch Package` (`.pak` `.ucas` `.utoc`)

> [!NOTE]
> The current workflow demonstrated in this project can only roll back characters whose asset structure has not changed. If a character's asset structure has undergone significant changes, the patch package generated by following this project's current workflow may cause the game to crash.
> 
> Future updates will consider using tools like [UAssetAPI](https://github.com/atenfyr/UAssetAPI) to address such issues.

## Usage Steps

### 1. Download the game version you wish to roll back to

Read [How to Download Historical Versions of Steam Games](/docs/DownloadHistoryVersion.md) for guidance

### 2. Use [FModel](https://github.com/4sval/FModel) to export relevant assets from the historical game version

Character skill data in ENDER LILIES is primarily located in the `EnderLilies/Content/_Zenith/Gameplay/Abilities/` path

You only need to export the assets for the characters you wish to roll back

The image below uses `Dark Witch Elaine` as an example. You only need to click the `Export Folder's Packages Raw Data (.uasset)` option

![export_uasset_by_fmodel](/docs/images/export_uasset_by_fmodel.png)

After exporting, move the exported content to this project while maintaining the original project path structure. This project provides skill rollback examples for `Dark Witch Elaine` and `Fallen Archer`. Be sure to refer to the internal structure of the [Exports](Exports) folder in this project to ensure the file structure is correct.

### 3. Modify the `GAME_DIR` in [pak.bat](pak.bat) to your actual game path
```bat
@echo off
rem Set your actual directory
set GAME_DIR=C:\Game\Steam\steamapps\common\ENDER LILIES\EnderLilies\Content\Paks
```

This path should point to the `Paks` folder, and the corresponding game should be the version you want to inject the patch package into

> [!NOTE]
> Make sure the `Paks` folder does not contain any non-official original files or mods. If there are any, please move these files to another location first.

### 4. Generate the patch files

Double-click `pak.bat` or enter `.\pak.bat` in the terminal within the project directory to execute and generate the patch package

The generated patch package is saved by default in the `dist` folder of this project, with the default name `EnderLilies_CustomRollback`

### 5. Install the patch files

Place the `EnderLilies_CustomRollback` folder into the `Paks` folder, for example:
```
...\Steam\steamapps\common\ENDER LILIES\EnderLilies\Content\Paks\
```

Then run the game to verify the results
